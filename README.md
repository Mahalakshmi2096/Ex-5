# UI-UX Experiment-5 CASE STUDY

### AIM:
To identify UX problems, analyze user pain points, select appropriate UX research methods, and create user personas for two different application scenarios using user-centered design principles.
 
### ALGORITHM:
### Step 1:

Select two different UX project scenarios:

Health & Fitness Mobile Application (“FitLife”)
E-Commerce Shopping Website (“ShopEase”)
### Step 2:

Study the target users and identify common user pain points in each application.

### Step 3:

Write clear UX problem statements using the format:

“[User] needs a way to [achieve goal] because [obstacle], which results in [impact].”

### Step 4:

Identify suitable UX research methods such as:

User Interviews
Surveys
Usability Testing
Analytics Review
### Step 5:

Justify why each research method is appropriate for understanding user behavior and usability issues.

### Step 6:

Create user personas based on user scenarios and research findings.

### Step 7:

Include the following details in each persona:


Demographics
Goals
Behaviors
Pain Points
Motivation
### Step 8:

Analyze how the personas and research methods help improve the user experience of the applications.

### RESULT:
Thus, the UX experiment was successfully completed by identifying user pain points, writing UX problem statements, selecting suitable research methods, and creating personas for two different scenarios: a Health & Fitness Mobile Application and an E-Commerce Shopping Website.
The experiment helped in understanding how user-centered design methods improve usability, accessibility, navigation, and overall user satisfaction in real-world applications.
